# Product context

**Audience:** A 30-minute talk for people familiar with chat-based AI tools but new to AI work systems. Visitors use phones during the session and may return later; the speaker also projects the same interface.

**Job:** Explain how a single registration-form request can become a controlled workflow, without claiming that prompts or automation eliminate errors.

**Scope:** Static, Spanish-language educational experience. One shared example, guided and free navigation, an interactive concept atlas, three deterministic simulation scenarios, a relationship map, and a sourced SDD/ODD comparison.

**Constraints:** No accounts, API keys, AI service calls, backend, shared progress or required runtime network. Save only local navigation progress. Label every simulation as simulated and predefined. Keep the terminology platform-dependent where appropriate.
